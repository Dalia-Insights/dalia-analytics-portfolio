# Dalia Hassan — Analytics Manager Portfolio

This is a single-page static portfolio tailored to Analytics Manager roles in high-growth tech / marketplace / logistics companies.

## Files
- `index.html` — complete portfolio app. No build step required.

## How to use
1. Double-click `index.html` to preview locally.
2. For public hosting, upload it to GitHub Pages, Netlify, Vercel, or any static web host.
3. Before publishing, replace synthetic/sanitized impact statements only with outcomes you can verify and safely disclose.
4. Add your CV PDF and a contact email if you want recruiters to contact you directly.

## Why these projects were selected
The portfolio emphasizes:
- analytics strategy and KPI frameworks
- cross-functional business decision support
- operational excellence
- customer / CX analytics and capacity planning
- self-service BI and automation
- forecasting and root-cause analytics
- data quality / governance mindset

These themes align strongly with Analytics Manager responsibilities in tech platforms.
